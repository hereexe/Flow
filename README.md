---

## ⚡ Возможности

- **Перевод на месте (In-Place):** Выделите текст в любом приложении (браузер, мессенджер, IDE, Word) или оставьте курсор в поле ввода, нажмите горячую клавишу — и текст заменится переводом.
- **Автоопределение направления:** Мгновенно распознаёт язык (RU ⇄ EN и другие) без переключения тумблеров.
- **Поддержка популярных провайдеров (BYOK):**
  - Google Translate API
  - DeepL API
  - Azure Translator
- **Стильный HUD-индикатор:** Анимированная плашка статуса ("Перевод...", "Готово", "Ошибка") в нижней части экрана.
- **Безопасное хранение ключей:** Все API-ключи шифруются и сохраняются в системном хранилище *Windows Credential Manager*.
- **Работа в фоновом режиме:** Приложение незаметно работает в системном трее Windows и потребляет минимум ресурсов.
- **Сохранение буфера обмена:** Исходное содержимое буфера обмена (включая форматированный текст и картинки) полностью восстанавливается после вставки перевода.

## 🚀 Установка

Перейдите на страницу **[Releases](../../releases)** и скачайте нужный вариант:

### Вариант 1: Инсталлятор (`Flow-Setup.exe`) — *Рекомендуется*
1. Скачайте `Flow-Setup.exe` и запустите его.
2. При необходимости нажмите **«Обзор...»** и выберите любую папку для установки (по умолчанию программа ставится в папку пользователя без запроса прав администратора).
3. Инсталлятор автоматически создаст ярлыки в меню «Пуск» и на Рабочем столе.

### Вариант 2: Портативная версия (`Flow-Portable-win-x64.zip`)
1. Скачайте `.zip` архив.
2. Распакуйте в любую удобную папку и запустите `Flow.Presentation.exe`.
3. Установка .NET Runtime не требуется (все зависимости уже включены в сборку).

> 💡 **Замечание о Windows SmartScreen:**  
> При первом запуске Защитник Windows (SmartScreen) может показать предупреждение о «неопознанном издателе».  
> Нажмите **«Подробнее» (More info) ➔ «Выполнить в любом случае» (Run anyway)**.

## 🛠 Быстрый старт

1. После запуска найдите иконку **Flow** в системном трее Windows (возле часов).
2. Нажмите правой кнопкой мыши по иконке ➔ выберите **Settings** (Настройки).
3. В окне настроек:
   - Выберите онлайн-провайдера (например, *Google Translate*, *DeepL* или *Azure*).
   - Введите ваш персональный API-ключ.
   - Настройте удобную комбинацию горячих клавиш (по умолчанию: `Ctrl + Shift + T`).
   - Нажмите **Save**.
4. Готово! Теперь при нажатии хоткея в любом месте текст будет мгновенно переводиться.

## 💻 Сборка из исходников

Требования: [.NET 10.0 SDK](https://dotnet.microsoft.com/download)

```powershell

git clone https://github.com/your-username/Flow.git
cd Flow

# Сборка и запуск тестов
dotnet build
dotnet test

# Локальная сборка релиза (Self-contained)
powershell -ExecutionPolicy Bypass -File ./build-release.ps1
```
